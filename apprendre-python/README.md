# Apprendre Python 🐍

Un petit cours progressif, en français. Chaque leçon est un fichier Python
commenté que tu peux **lire** puis **exécuter**.

## Comment l'utiliser

```bash
cd apprendre-python
python3 01_les_bases.py        # lance une leçon
python3 verifier.py            # vérifie tes exercices
```

## Programme

| # | Fichier | Ce que tu apprends |
|---|---------|--------------------|
| 1 | `01_les_bases.py` | `print`, variables, types, calculs, `input` |
| 2 | `02_conditions.py` | `if` / `elif` / `else`, comparaisons, `and` / `or` |
| 3 | `03_boucles.py` | `for`, `range`, `while`, `break` |
| 4 | `04_listes_dictionnaires.py` | listes, dictionnaires, parcourir des données |
| 5 | `05_fonctions.py` | `def`, paramètres, `return` |
| 6 | `06_projet_devine_nombre.py` | mini-jeu qui réutilise tout |

## Méthode conseillée

1. Lis la leçon, lance-la, puis **modifie le code** pour voir ce qui change.
2. Ouvre `exercices.py` et complète les fonctions de la leçon correspondante.
3. Lance `python3 verifier.py` : il te dit ce qui est juste ✅ ou faux ❌.
4. Bloqué·e ? Regarde `solutions.py` — mais seulement après avoir essayé !

Les erreurs sont normales : lis le message (surtout la dernière ligne),
il dit souvent exactement ce qui ne va pas.
